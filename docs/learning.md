# Continuous Learning

Canonical: `core/protocol/learning.md`; role: `core/roles/retro-learner.md`.

After every delivery, the Retro phase mines the run — refuted findings (reviewer
over-flagging), wrong take-care assumptions, fix-loop root causes, supervision
violations, friction — and appends deduplicated, imperative lessons to
`.aidd/learnings.md`. Master and Inception load the file, and reviewers read damping
lessons so refuted finding classes are not re-raised. Lessons are advisory context;
they never override the constitution or protocol.
