# Autonomy Modes

Canonical: `core/protocol/autonomy-modes.md`. Summary:

| | take-care | let-me-look |
|---|---|---|
| G1/G2/G3 | auto-approved (identical ledger entry) | pause: approve / revise / abort |
| Clarifying questions | self-answered, logged as Assumptions (H/M/L) | asked of you |
| BLOCKING questions | still escalate to you | asked of you |
| On blocked | finishes what it can, reports | stops and asks |
| Quality gates | identical — never relaxed | identical |

Choose per change: start in `take-care`, drop to `let-me-look` before the pre-merge gate
with `/aidd:mode let-me-look` — or the reverse. The audit trail reads the same either way:
that is the point.
