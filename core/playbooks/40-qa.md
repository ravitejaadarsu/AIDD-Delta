# Phase: QA

Purpose: post-implementation review with adversarial verification, an exhaustive
test-engineering pass, clean-state E2E + mutation, post evidence, the AC matrix, and a
single consolidated critic verdict. Only CONFIRMED findings, executed test FAILs, and a
REJECT verdict block.

## Steps

Phase boundary: rebuild the snapshot pack
(`bash .aidd/framework/scripts/build-snapshot.sh pre-qa` per
`../protocol/context-snapshots.md`) before Step 1.

1. **Post-implementation review** — fan out Reviewer (`../roles/reviewer.md`) `mode: post`
   over the full Construction diff, dimensions: correctness, security, performance,
   test-coverage, spec-compliance → `qa/findings-<dimension>.md`. In parallel: Security
   Auditor (`../roles/security-auditor.md`) → `qa/security-report.md` (incl. the CWE/CVSS
   threat matrix).
2. **Collate & dedupe** (orchestrator): same file+line+claim merges keeping highest
   severity → numbered master list `qa/findings.md`.
3. **Adversarial verification** — fan out Adversarial Verifier
   (`../roles/adversarial-verifier.md`), one per CRITICAL/HIGH finding (file-grouped if
   >12; cap 6) → `qa/verdicts.md`. CONFIRMED = blocking; PLAUSIBLE + MEDIUM/LOW =
   advisory; REFUTED = dropped with evidence.
4. **Exhaustive testing** — fan out Test Engineer (`../roles/test-engineer.md`), one per
   test category (functional-happy-path, negative-error-handling, boundary-edge,
   impossible-abuse, api-contract, state-concurrency-idempotency, regression-compat,
   performance-smoke; cap 6). Each designs AND executes an exhaustive case matrix →
   `qa/tests/<category>.md`; orchestrator consolidates → `qa/test-report.md`. Every
   executed FAIL becomes a fix-loop defect. Sets `exhaustive_tests_passed`.
5. **Fix loop** (max 3 iterations, shared budget) — consumes BOTH CONFIRMED findings and
   test-report FAILs:
   - Group defects by ownership; re-dispatch the owning Builder with them appended to its
     story file. Fixes are TDD (reproducing test first).
   - `scope=ARCHITECTURE` findings skip the loop → backflow (below).
   - Re-run integration; re-run ONLY affected reviewer dimensions and test categories.
6. **E2E verification** — E2E Verifier (`../roles/e2e-verifier.md`): clean-state run of ALL
   canonical commands + mutation testing → `qa/verification-report.md`. Red re-enters the
   fix loop. Sets tests_green / e2e_verified / mutation_floor_met.
7. **Post evidence** — Evidence Capturer `stage: post` → `evidence/post/` + manifest +
   perf-budget check → evidence_captured / perf_within_budget. (Optionally re-dispatch the
   Impact Analyst in QA mode to confirm actual reach matched `impact-report.md`.)
8. **AC matrix** — AC Assessor (`../roles/ac-assessor.md`) → `ac-matrix.md`; FAILs feed the
   fix loop → acs_verified.
9. **Test report approval & story annotation** — present `qa/test-report.md`. On approval
   (`take-care`: auto unless a FAIL remains) record `g_test_report` and write a
   `## Test Report` section into each affected story (`../protocol/gates.md`).
10. Orchestrator computes the QA verdict + score (see `50-delivery.md`), sets
    qa_findings_resolved / security_clean.
11. **Critic verdict** — dispatch Critic (`../roles/critic.md`) → `qa/critic-verdict.md`:
    one consolidated verdict (APPROVE / APPROVE WITH CONDITIONS / REJECT) synthesizing the
    verification report, adversarial verdicts, test report, AC matrix, impact report,
    security report, and supervision. Sets `critic_approved` (APPROVE→passed,
    CONDITIONS→passed with the conditions recorded, REJECT→failed → re-enter fix loop or
    escalate). Conditions/blockers go verbatim into the PR body.
12. **Supervisor audit** → **GATE G3** (`g3_premerge`).

## Backflow (once per run)

Architect ADR amendment → Epic Scoper delta stories (disjointness re-checked) → G2
re-gates (`G2.n`) → delta Construction → QA over the delta diff + final full E2E.
A second architecture-scope confirmation = run FAIL + escalation.

## Fix-loop exhaustion

Verdict FAIL; G3 forced-human even in take-care. Options: accept-with-waiver, redirect
(notes → one bonus iteration), abort.

## Exit checklist

- [ ] zero open CONFIRMED findings; advisory itemized
- [ ] exhaustive test report PASS (`exhaustive_tests_passed`); no open executed FAIL
- [ ] critic verdict APPROVE or APPROVE WITH CONDITIONS (`critic_approved`); no REJECT
- [ ] every affected story annotated with its Test Report link (g_test_report recorded)
- [ ] verification report green, clean-state, with evidence
- [ ] mutation ≥ floor; coverage ≥ target (or CONCERNS)
- [ ] evidence/post + manifest complete; perf within budget
- [ ] AC matrix: every AC PASS
- [ ] G3 approved
